# SOC Journey

My hands-on journey learning Security Operations Center (SOC) concepts.

## What I am learning

- Understanding common cyber attacks
- Identifying evidence created by attacks
- Reading and analyzing logs
- Understanding how SOC analysts investigate alerts
- Learning network and web security monitoring

## Attacks Covered

- Brute-Force Attack
- Port Scanning
- SQL Injection
- Phishing
- DDoS
- Credential Theft

## My Learning Approach

For each attack, I focus on:

1. What is the attack?
2. What is the attacker's goal?
3. How does it work?
4. What evidence does it create?
5. Where can that evidence be found?
6. How can a SOC analyst detect it?
7. How can the incident be investigated?
8. How can it be prevented?
